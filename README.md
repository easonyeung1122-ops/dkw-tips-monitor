# dkw-tips-monitor

**美债通胀补偿高频监测。** 把美联储官方的 DKW 期限结构分解与 Bloomberg 实盘数据拼成一条日频流水线，回答一个问题：

> 通胀补偿（IC）今天的变动，里面有多少是**通胀预期**，有多少是**风险溢价 / 流动性**，有多少是**模型解释不了**的？

现有工具大多停在"读盈亏平衡通胀率（breakeven）"这一步。但那是个复合量。美联储自己的分解显示：

```
TIPS 通胀补偿 IC = 预期通胀 + 通胀风险溢价 − TIPS 流动性溢价
```

只要后两项不为零，IC 就偏离真实预期。**拿 IC 的日度跳动当通胀预期变化读，读到的其实是风险溢价和流动性。** 本工具把这句话变成可每日执行的流程。

---

## 它产出什么

一条命令生成 `UST_IC_<date>.md`（第 0 节 + 七节，按可靠性递减分层）：

| 节 | 内容 | 可靠性 |
|---|---|---|
| **0** | **大白话版**：一段不带术语的结论解读，每次运行必出（同时打到 stdout） | 派生自下方数值，不引入新数据 |
| 1 | 市场侧分解（**零模型**）：1.1 水平快照 + 1.2 变动矩阵，覆盖 5y/10y/20y/30y/5y5y/10y10y/20y10y | 最可靠 |
| 2 | Fed DKW 分解：三期限 × 五成分 + IC + z 分 | 权威，但落后 2–3 周 |
| 3 | 归因：`ΔIC(市场) = Δ预期通胀 + ΔIRP − ΔTIPS流动性溢价 + Δ残差` | Fed 覆盖期内**精确可加** |
| 4 | 4.1 Fed 口径残差 + **4.2 实时残差**（推到最新交易日，自算） | 4.2 是唯一带 z 分、可直接用的输出 |
| 5 | 桥接外推至最新交易日 + 样本外误差带 | 自算估计 |
| 6 | 情绪联动：IC 周变动与 HY OAS / VIX / Brent 的相关性 | 观测 |
| 7 | 数据溯源与限制 | — |

### 第 0 节样例（真实输出，2026-09-17）

> 先看时间差：美联储那份分解最后一次更新是 2026-08-31，到今天中间隔了 13 个交易日……把这段名义收益率的变动拆开看（近一个月，10 年期）：名义 +35.3bp，其中「实际利率」——借真钱、扣掉通胀后的成本——+32.9bp，「通胀那一块」只有 +2.4bp。也就是说，**大约 93% 的波动来自实际利率，这波跟通胀定价基本没关系。** 再说通胀预期本身有没有动：**读不出来**，这几天的变化里最大的一块（−6.1bp）落在模型解释不了的地方……
> **一句话：这波收益率变动主要是实际利率的事，通胀预期基本没参与。**

保留这一段是因为它体现了工具的设计立场：**先用零模型的市场数据回答"谁在推"，再用 Fed 分解回答"是不是预期"，最后才谈错价**，且每一步的显著性口径都写清楚。

## 快速开始

```bash
git clone https://github.com/easonyeung1122-ops/dkw-tips-monitor.git
cd dkw-tips-monitor

# 首次运行自动下载两个数据源（Fed CSV ≈ 4.6MB，Bloomberg 面板 ≈ 1.1MB）
python scripts/run.py --outdir ./out
```

输出：`./out/UST_IC_<date>.md` + 终端一段白话解读。

**依赖**：`pandas` / `numpy` / `blpapi`。Bloomberg 需要终端登录且 `bbcomm` 在跑；没有终端时加 `--no-bbg` 自动降级为纯 Fed 侧。

### 参数

| 参数 | 说明 |
|---|---|
| `--asof YYYY-MM-DD` | 复现历史某日截面；默认取最新可用交易日 |
| `--outdir PATH` | 报告落盘目录，默认 `<skill>/reports` |

```bash
python scripts/dkw_fetch.py    # 下载 + 解析 + 恒等式校验 + 打印 vintage 说明
```

## 核心技术点

### 1. Fed 的会计恒等式（全样本验证）

```
nominal.yield.fitted = exp.real.short.rate + exp.inflation + real.term.prem + inflation.risk.prem
ic.fitted            = exp.inflation + inflation.risk.prem − tips.liq.prem
```

在 **11,391 个交易日（1983-01-03 起）** 上逐日校验，两条恒等式最大误差 **6e-14** —— 完全自洽。
由此第 3 节的归因项**严格加总**等于市场 IC 的变动，不是近似。

### 2. 桥接外推：把 2–3 周的发布滞后补上

Fed 序列每月第 4 个工作日发布，前推至上月最后工作日 → 常年落后最新交易日约 2–3 周。本工具用滚动岭回归拟合各成分的**日变动**，再锚定 Fed 最后发布的水平：

```
d(component)_t = a + b'·dX_t + e_t      X = Δ实际收益率、Δ盈亏平衡、ΔVIX、ΔHY OAS、Δ油价、ΔMOVE
component_t    = anchor + γ · Σ_{s≤t} d(component)_s
```

- λ 与 γ 都在**较早的 400 日切片**上选，指标在**之后未用于选参的 400 日**上计算，基准是随机漫步。
- 误差带取**验证期实测 h 日误差的 95% 分位**，不用 `1.96 × 1 日 RMSE × √h` —— 桥接误差高度自相关，√h 会把带宽低估近一个数量级。

**样本外表现（13 日口径，400 日未触碰切片）**：R² **0.87–0.97**，`ic.fitted.10` RMSE 2.24bp、95% 带 ±4.7bp。

### 3. 实时残差：绕过跨源口径差

"TIPS 相对模型贵还是便宜"是全篇唯一带 z 分、可直接判断的量，但 Fed 版本滞后 2–3 周。**按水平跨源刷新不成立**：Bloomberg 反推的 IC 与 Fed `ic.raw` 不是同一个测量，水平基差均值 +2.3bp、sd 4.5bp(10y) / 11.6bp(5y5y)，与信号同量级。

改用**变动口径** `resid_live = resid_锚点 + [ΔIC(市场) − ΔIC(拟合)]`，常数基差在差分中自动抵消。误差带按方差相加 `√(band_nom² + band_ic²)`。

**读法**：`z_live` 判**水平**显著性（跨年尺度），`|d_bp| vs band_bp` 判**近期变化**显著性（短期）—— **两个都要过**。只看前者会把"早就存在的偏离"讲成"刚出现的错价"。

## 报告怎么读（决策路径）

**只看一段**就先读第 0 节；要核对或自己重算，再按顺序翻表：

| 想问 | 看哪 | 判据 |
|---|---|---|
| 名义利率这波是通胀还是实际利率在动？ | 1.1 + 1.2 | `Δ实际/Δ名义` > 80% → 实际利率主导，与通胀预期无关。**零模型、实时**，不用等 Fed |
| 通胀**预期**本身动了吗？ | 1.2 → 第 3 节 | 1.2 只给幅度；第 3 节取绝对值最大的成分当定性 |
| 有没有可交易的错价？ | 4.2 实时残差 | `z_live` 与 `\|d_bp\| vs band_bp` **两个都要过** |
| 这几天实际发生了什么？ | 5 + 6 节 | 6 节风险因子 >0.5σ 则该周 IC 变动倾向溢价渠道 |

**三个最常犯的错**：① 把盈亏平衡的变动读成通胀预期（只有第 3 节"预期通胀"为最大项时才成立）；② 拿 4.1 的 z 直接下单（锚点常落后 2–3 周）；③ 把"水平显著"当"刚出现"（两者尺度不同，要分开过）。

## 已知限制

- **桥接外推是自算估计，不是 Fed 数据。** 报告中一律如此标注。gap 越长误差越大，务必读误差带。
- **`z_live` 的分母是 Fed 口径过去 5 年标准差**，跨期可比性有限（模型参数会随 vintage 变化）。
- **残差反映的是"相对模型"的偏离，不是无风险套利。** 它可以是模型设定误差、TIPS 供需、或未建模的流动性。
- 本工具是**分解原料**，不是信号机；不构成投资建议。
